Meta WhatsApp Cloud API

Farmer Interface & Messaging Gateway (v20.0)
What it does: Provides frictionless interaction through farmers' native WhatsApp application without requiring any custom mobile app downloads.

Engineering Details:

  • In-memory LRU deduplication cache + PostgreSQL database check guarantees zero duplicate outbound replies.
  • Automatic downloading of WhatsApp photos with magic-byte validation (JPEG: FF D8 FF, PNG: 89 50 4E 47).

Google Gemini 3.1 Flash-Lite

Botanical Multimodal Vision & Synthesis
What it does: Inspects leaf close-ups for morphological symptoms and synthesizes complex agronomic data into simple, empathetic farmer advisories.

Engineering Details:
  • Enforces a strict 6-field JSON schema: visible_symptoms, image_quality, possible_explanations, missing_evidence, field_verification_recommended, non_definitive_statement.
  • Guaranteed non-definitive constraint: strictly labels all causes as unconfirmed provisional hypotheses to prevent pesticide misuse.
  • Deterministic botanical fallback active if API quotas or network limits occur.

Open-Meteo Weather API

Hyper-Local Microclimate Telemetry
What it does: Fetches high-resolution numerical weather prediction (NWP) telemetry at the exact latitude/longitude coordinates of the farmer's field.

Engineering Details:
  • Collects temperature, relative humidity, dew point, wind speed, and 48-hour accumulated rainfall.
  • Computes derived agronomic risk indicators: extended high-humidity streak (>85% RH for >14h), thermal heat shock (>38°C), and consecutive wet days.
  • 15-minute in-memory caching to minimize external network latency.
  • Zero-fabrication boundary: missing coordinates return status: 'unavailable' without fabricating values.
ECMWF / GFS Models 15-Min LRU Cache services/weatherService.js

Copernicus Sentinel-2 Grid

Orbital Vegetation Index & Canopy Biomass
What it does: Analyzes 10m multispectral satellite reflectance to calculate the Normalized Difference Vegetation Index (NDVI) and quantify canopy vigor changes.

Engineering Details:
  • Calculates \(\text{NDVI} = \frac{\text{NIR} - \text{Red}}{\text{NIR} + \text{Red}}\) and evaluates multi-temporal canopy decline ($\Delta\text{NDVI}$).
  • Automated optical cloud contamination gate: passes with >70% cloud cover are rejected safely to prevent false biomass drop warnings.
  • Controlled sample-data pathway for presentations, explicitly tagged with is_sample: true.
10m Resolution >70% Cloud Rejection services/vegetationService.js

The 5-Agent Cooperative Architecture

Instead of relying on a single monolith prompt, AgriGuard coordinates 5 specialized agents that execute in an asynchronous dependency chain:

Role 1

Intake Agent

Identifies the farmer phone number, looks up active field plots, parses GPS coordinates or WhatsApp location pins, validates media formats, and detects registration triggers.

Role 2

Data Collection Agent

Queries Open-Meteo for microclimate telemetry and the Sentinel-2 adapter for NDVI biomass indices concurrently in parallel without blocking the main event loop.

Role 3

Crop Context Agent

Injects crop variety phenology and growth stage vulnerability (e.g. Paddy tillering vs. panicle emergence; Cotton flowering vs. boll development).

Role 4

Risk Assessment Engine

Executes transparent biological rules, compiles multi-source evidence matrices, determines risk level (LOW/MODERATE/HIGH/INSUFFICIENT), and calculates composite confidence scores.

Role 5

Evidence & Explanation Agent

Uses Gemini 3.1 Flash-Lite to translate raw mathematical matrices into farmer-friendly WhatsApp advisories with safe cultural next steps and mandatory non-definitive disclaimers.

Role 6

Notification Agent

Enforces conservative alert policy: strictly suppresses proactive alerts for low-risk or ambiguous reports, and enforces a 24-hour duplicate alert suppression window.

Mathematical & Agronomic Risk Formulations

1. Rice Blast Fungal Index (\(I_{\text{blast}}\))

Evaluates Magnaporthe oryzae conidial spore germination and foliar penetration favorability:

If (RH ≥ 90% && 20°C ≤ Temp ≤ 28°C && LeafWetness > 14h):
  → Favorability = HIGH (Score = 88-95)
If (RH ≥ 85% && 18°C ≤ Temp ≤ 32°C):
  → Favorability = MODERATE (Score = 55-75)
Else:
  → Favorability = LOW (Score < 35)

2. Thermal Desiccation Stress Index (\(I_{\text{heat}}\))

Detects Cotton bloom square shedding and pollen desiccation caused by acute heat waves:

If (MaxTemp ≥ 38.0°C && RH ≤ 40% && DryDays ≥ 7):
  → Abiotic Stress = SEVERE THERMAL SHOCK
  → Classification: Non-Pathogenic Physiological Stress
  → Action: Early morning irrigation; avoid sprays

3. Multi-Temporal NDVI Canopy Trend (\(\Delta\text{NDVI}\))

Evaluates Sentinel-2 multispectral vegetation reflectance across orbital revisit cycles:

ΔNDVI = NDVI(Current Pass) - NDVI(T-6 Day Pass)
If (ΔNDVI ≤ -0.10):
  → Trend: 'rapid_canopy_decline'
If (ΔNDVI >= +0.02):
  → Trend: 'positive_canopy_growth'

4. Optical Cloud Gate Rejection Policy

Prevents cloud and shadow reflectance from causing erroneous crop health drop detections:

If (CloudCoverPercent > 70.0%):
  → Quality: Usable = false, Rejection = true
  → Fallback: Tag cloud occlusion in dossier
  → Never fabricate clear-sky NDVI values
The 4 Safety & Agronomic Guardrails

1. Non-Definitive Diagnosis

AI models can easily mistake foliar blight for brown spot or potassium chlorosis. AgriGuard AI enforces that all causes are labeled as unconfirmed provisional hypotheses, always directing farmers to verify with extension officers before applying expensive chemicals.

2. Zero Data Fabrication

If a farmer sends a report without GPS coordinates, or if Open-Meteo is temporarily unreachable, the system never invents fake temperatures or rainfall. Missing fields remain null and are explicitly listed in the dossier as missing evidence.

3. Farmer Privacy Masking

To protect smallholder farmers' Personally Identifiable Information (PII), all phone numbers in the Operations Center UI and API endpoints are masked (e.g. +91 •••• 1203).

4. Alert Fatigue Prevention

High-severity alerts require strict agronomic threshold verification. A conservative notification policy suppresses alerts for ambiguous complaints, and an active 24-hour suppression window blocks duplicate alarms.
